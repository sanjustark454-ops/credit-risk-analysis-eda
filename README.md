# Credit Risk Analysis & EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on credit risk data to identify patterns and risk factors.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Data cleaning
- Missing value handling
- Distribution analysis
- Correlation analysis
- Risk pattern exploration

- Credit_Risk_Analysis+EDA.ipynb
